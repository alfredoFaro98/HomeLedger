Come importare un CSV

Il file deve avere una prima riga di intestazione con i nomi delle colonne (separate da virgola). Colonne riconosciute:

Colonna Obbligatoria Formato
date / data Sì AAAA-MM-GG, es. 2026-08-31
amount / importo Sì Numero, es. -42.50 (il segno è opzionale se indichi il tipo)
kind / tipo No income, expense o transfer (dedotto dal segno se assente)
account / conto No Nome di un conto esistente (altrimenti si usa il primo conto)
transfer_account / conto_destinazione Solo per i trasferimenti Nome del conto di destinazione
category / categoria No Nome categoria (testo libero)
counterparty / controparte No Testo libero
description / descrizione No Testo libero

Esempio:

date,amount,kind,account,category,description
2026-08-15,-42.50,expense,Conto principale,Spesa,Supermercato
2026-08-01,1850.00,income,Conto principale,Stipendio,Stipendio agosto
